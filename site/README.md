# site/ — النسخة العامة

`index.html` هنا نسخة من `demo/hissa-live.html` مُعدّة لاستضافة ثابتة:

1. **الحسابات الحقيقية محذوفة.** الحالة المنشورة على الرابط الخاص تحتوي حسابات
   سجّلها أشخاص فعليون ببريدهم وتجزئة كلمة مرورهم. الرابط العام ليس مكانها،
   فتُزال قبل النسخ ولا يبقى إلا حسابات البذرة التجريبية.

2. **لا حفظ للجميع.** الاستضافة الثابتة لا توفّر `window.claude`، فيبقى
   `WRITER` فارغًا ويعمل التطبيق في وضع الجلسة: كل شيء يعمل، وما تغيّره يبقى
   في تبويبك ولا يراه غيرك ولا يبقى بعد إعادة التحميل. الصفحة تقول ذلك في
   شريط الحالة وفي التذييل.

يولَّد هذا الملف من `demo/hissa-live.html` عبر `demo/tools/make_public.py`.
